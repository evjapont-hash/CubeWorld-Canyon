Canyon - Voxel Landscape

Creator: Evan Pontrich | Project 2: Cube World

Info: Procedural landscape generated via WebGL matrix transformations of a single 2x2x2 cube primitive. Features distance fog, heightmap image sampling, and Bezier curve skyscape animations.

Note: You must run this using a local web server (e.g., VSCode Live Server) to allow the JavaScript to sample the local image files without CORS errors.
